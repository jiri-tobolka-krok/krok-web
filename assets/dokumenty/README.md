# Dokumenty ke stažení

Sem patří PDF soubory, na které odkazuje `dokumenty.html`:

- `skolni-rad.pdf`
- `klasifikacni-rad.pdf`
- `zapisy-skolska-rada/` — jednotlivé zápisy, pojmenované `2026-09-15.pdf` apod.

Po nahrání souboru je potřeba na stránce `dokumenty.html` nahradit
`<span class="todo">doplnit soubor</span>` odkazem, například:

```html
<a href="assets/dokumenty/skolni-rad.pdf" download>Stáhnout PDF</a>
```
